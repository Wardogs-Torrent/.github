## 🚨 FAKE TORRENT DETECTION — `RECOGNIZE → AVOID → REPORT`

Every fake WARDOGS torrent or cheat download follows the same recognizable pattern.

- **No Real Torrent Exists** — Cheats for kernel-anticheat games like WARDOGS are never distributed via torrent. Any torrent file claiming to contain a WARDOGS cheat is malware.
- **Password-Protected ZIPs** — Scam repositories often distribute ZIP archives via Mega.nz or Discord with a password like `5868781`. The password exists to bypass automated malware scanners.
- **Antivirus Disable Instructions** — Every fake cheat instructs you to disable Windows Defender, SmartScreen, or your entire antivirus before running the file.
- **Purchased GitHub Stars** — Fake repositories have inflated star counts to appear legitimate, but the code is obfuscated or missing entirely.

`TORRENT → SCAN → REPORT`

## 🖥️ DMA & HARDWARE RISKS — `HARDWARE → RISK → REALITY`

What "private DMA cheats" actually require and what they expose.

- **Second PC Required** — DMA cheats require a physical DMA card and a second computer to read memory externally.
- **Secure Boot Disabled** — Many DMA setups require disabling Secure Boot, Windows Defender, and SmartScreen—leaving your system exposed to other threats.
- **Not Undetectable** — Kernel anticheats like Elytra are specifically designed to detect DMA hardware and behavior.
- **High Cost, High Risk** — DMA cards cost hundreds of dollars, and a ban means losing both the account and the hardware investment.

`HARDWARE → COST → RISK`
